# CozyMTG

A cozy, single-player Magic: The Gathering collecting game. Travel through Magic's history
era by era, play matches against the AI, earn gold, open booster packs, fill your collection
and build decks from what you pulled. It runs offline, there are no real-money purchases, and
it's fine to play in short, relaxed sessions.

## True to the real products

CozyMTG tries to feel like buying Magic at the time each set was in stores:

- **Real pack contents.** Each booster follows its set's real slot layout (the number of
  commons, uncommons and rares, plus land and special slots). It holds the actual printings
  from that set, with their real card images.
- **Products stay in their era.** The shop only sells boosters, preconstructed decks and other
  products that were really on sale in the current era. Opponents use only cards that existed
  at that time.
- **The real look.** The shop shows real photos of booster wrappers, boxes and deck boxes.
- **The real rules.** Matches run on the [Forge](https://github.com/Card-Forge/forge) rules
  engine and its AI, so cards work like they do at a real table.
- **Era-legal decks.** You build decks only from cards you own that are legal in the current
  era.

## Playing

The latest stand-alone build is under **Releases**. Unzip it and run `CozyMTG.x86_64` (Linux)
or `CozyMTG.exe` (Windows). You don't need to install anything. Card images download from
Scryfall the first time they're shown.

You start with 300 gold and a starter deck. Win matches to earn gold, buy packs in the shop
and improve your deck in the deck builder.
